# H0002 — Observations protocolaires non normatives

Ces observations sont produites après l'expérience. Elles ne modifient ni H0002 ni le
Protocole Contradictoire.

1. Ancrer le premier run avant les mutants distingue une généralisation observée d'une
   correction guidée par les tests : ici, le ledger H0001 a passé les cinq cas sans
   modification.
2. Une famille petite mais discriminante apporte davantage qu'une multiplication de cas
   voisins : signe du PnL, frais seuls, échelles et rationnels non terminaux ont exercé des
   chemins économiques différents sous les mêmes formules.
3. La suppression de l'identité et la permutation de la famille sont des contrôles simples
   contre le surajustement par scénario.
4. La séparation physique entre inputs de l'oracle et réponses préenregistrées reste utile
   même lorsque les deux vivent dans le même paquet Git.
5. Les limites restantes doivent alimenter une capability map P1 après revue; elles ne
   déterminent pas automatiquement H0003.

H0002 ne permet pas encore de conclure combien d'hypothèses sont nécessaires pour P1.
